01

La idea: copiar (muy mal) una neurona

Una neurona de verdad recibe señales por las dendritas, las junta en el cuerpo celular y, si la señal total es suficientemente fuerte, "dispara" un impulso por el axón. En 1943 McCulloch y Pitts lo pasaron a matemáticas. Así se traduce cada parte:

DendritasEntradas x₁, x₂…Los datos que llegan (humedad, nota, temperatura…).
Fuerza de la sinapsisPesos w₁, w₂…Cuánto importa cada entrada. Positivo empuja a "sí", negativo a "no".
Cuerpo celularSuma Σ + sesgo bJunta todo en un solo número z.
¿Dispara o no?Activación f(z)Decide la salida a partir de z.
AxónSalida ŷEl resultado, que puede ir a otra neurona.
La idea clave

Una neurona artificial es solo esto: multiplica, suma, decide. Todo lo demás de este tema (redes, capas, ReLU) es repetir eso muchas veces.

02

El perceptrón en 3 pasos

El perceptrón (Rosenblatt, 1957) es la neurona artificial más simple. Clasifica en dos grupos: 1 o 0, sí o no.

Paso 1 · multiplica y suma:  z = w₁·x₁ + w₂·x₂ + … + wₙ·xₙ + b Cada entrada por su peso, todo sumado, más el sesgo b. En algunos materiales a z le dicen A (es lo mismo).
Paso 2 · decide (función escalón):  ŷ = 1 si z ≥ 0  ·  ŷ = 0 si z < 0 Ojo: algunos ejercicios usan "1 si z > 0" (estrictamente mayor). Solo cambia algo cuando z da exactamente 0. Usa siempre la que diga tu enunciado.
Paso 3 · interpreta:  1 = clase "sí"  ·  0 = clase "no"
¿Y el sesgo b para qué?

Es el "umbral de exigencia". Un b muy negativo obliga a que las entradas sumen mucho antes de que la neurona diga 1. Un b positivo la vuelve fácil de convencer.

Laboratorio: mueve los pesos y mira la frontera

Los puntos son los datos del afiche (rojos = clase 0, azules = clase 1). La línea discontinua es donde z = 0: de un lado la neurona dice 1, del otro dice 0. El punto naranja es una entrada que tú mueves.

Su límite

Una sola neurona solo puede separar con una línea recta. Si los datos no se pueden separar así (el famoso XOR), el perceptrón no sirve. Por eso existen las redes con varias capas (clase 6).

Cómo aprende: corregir cuando se equivoca

"Aprender" significa ajustar pesos y sesgo. Le muestras un ejemplo con la respuesta correcta y (tu material a veces la llama d). Si acierta, no toca nada. Si falla, corrige un poquito:

error = y − ŷ
wᵢ ← wᵢ + α · error · xᵢ
b  ← b  + α · error α es la tasa de aprendizaje (qué tan grande es cada corrección, p. ej. 0.1). Como ŷ y y solo valen 0 o 1, el error solo puede ser −1, 0 o +1.

Una época es pasar una vez por todos los ejemplos. Se repiten épocas (sin reiniciar los pesos) hasta que una época completa no tenga errores.

z = 0.5(0) + 0.8(0) − 1.5 = −1.5 → ŷ = 0
error = 1 − 0 = 1

w₂ ← 0.8 + 0.1(1)(0) = 0.8
b  ← −1.5 + 0.1(1) = −1.4   (el sesgo siempre se corrige)

04

Ejercicio: ¿va a llover hoy?

Perceptrón de 4 entradas con pesos fijos (no se entrena, solo se evalúa).

EntradaVariableValorNormalizado (÷100)Peso
x₁Humedad relativa (%)800.800.4
x₂Probabilidad de lluvia (%)700.700.3
x₃Velocidad del viento (km/h)200.20−0.2
x₄Nubosidad (%)900.900.5

Sesgo b = −0.6 · activación: ŷ = 1 si z ≥ 0 (emitir alerta), 0 si z < 0.

Solución paso a paso
1 · NORMALIZAR

Se divide todo entre 100 para que las entradas queden en una escala parecida (0 a 1): x = (0.80, 0.70, 0.20, 0.90). Si no se normaliza, la nubosidad (90) aplastaría a todo lo demás solo por ser un número grande.

2 · COMBINACIÓN PONDERADA
z = 0.4(0.80) + 0.3(0.70) + (−0.2)(0.20) + 0.5(0.90) + (−0.6)
z = 0.32 + 0.21 − 0.04 + 0.45 − 0.6
z = 0.34
3 · ACTIVACIÓN

0.34 ≥ 0 → ŷ = 1. Se emite alerta de lluvia.

4 · ANÁLISIS

Las tres variables con peso positivo (humedad, probabilidad, nubosidad) aportan 0.32 + 0.21 + 0.45 = 0.98, que supera de sobra el sesgo de −0.6. El viento tiene peso negativo: entre más viento, menos probable la lluvia según el modelo (el viento dispersa las nubes). Aquí resta solo 0.04 porque hay poco viento. Para apagar la alerta, el viento tendría que restar más de 0.34; o sea 0.2·x₃ > 0.34, x₃ > 1.7, es decir más de 170 km/h.

06

Redes: muchas neuronas en capas, con ReLU

Una red neuronal es poner perceptrones en fila y en columna. Cada neurona hace exactamente lo mismo de antes (multiplica, suma, decide), pero su "decisión" ya no es 0 o 1:

ReLU(z) = máx(0, z) Si z es negativo, sale 0 (la neurona queda "apagada"). Si es positivo, sale z tal cual. Ejemplos: ReLU(−0.56) = 0 · ReLU(0.39) = 0.39.
  • Capa de entrada: no calcula nada. Solo entrega los datos (a = x).
  • Capas ocultas: cada neurona recibe todas las salidas de la capa anterior.
  • Capa de salida: igual, y su resultado es la respuesta de la red.

Calcular la red de izquierda a derecha se llama propagación hacia adelante. La salida de una capa es la entrada de la siguiente.

La notación que asusta (pero no muerde)

aj(l) = f( Σi wji(l) · ai(l−1) + bj(l) )
SímboloSe lee
(l)en qué capa estoy (1 = primera oculta)
aj(l)la salida de la neurona j de la capa l
wjillega a j, viene de i. Primero el destino, después el origen.
bj(l)el sesgo de esa neurona
Truco para las tablas de pesos

En la matriz W, cada fila es una neurona destino y cada columna es una neurona de la capa anterior. Para calcular la neurona j: toma la fila j, multiplica elemento por elemento con las salidas anteriores, suma y agrega su sesgo. El tamaño de W es (neuronas de esta capa) × (neuronas de la anterior).

Contar parámetros

Por cada capa: pesos = neuronas aquí × neuronas antes, y un sesgo por neurona. La entrada no tiene parámetros. Ejemplo para la red del maíz (4 → 4 → 4 → 2): (4×4 + 4) + (4×4 + 4) + (2×4 + 2) = 20 + 20 + 10 = 50.

Chuleta para el parcial

  1. Multiplica cada entrada por su peso, suma todo y suma el sesgo. Eso es z.
  2. Aplica la activación que diga el enunciado: escalón (0/1, mira si es > o ≥) o ReLU (máx(0, z)).
  3. En redes, la salida de una capa es la entrada de la siguiente. Una neurona apagada aporta 0 a todo lo que sigue.
  4. wji: llega a j, viene de i. Fila = destino.
  5. Entrenar (solo perceptrón): si falla, w ← w + α(y − ŷ)x y b ← b + α(y − ŷ).
Errores típicos
  • Olvidar sumar el sesgo, o sumarlo con el signo cambiado. Escribe siempre "+ (−0.36)".
  • Multiplicar mal los negativos: (−0.33)·(−0.30) = +0.099.
  • Aplicar ReLU a la capa de entrada. La entrada no tiene activación.
  • Redondear en cada paso. Trabaja con 4 decimales y redondea al final.
  • Leer w31 como "de 3 a 1". Es al revés: de 1 a 3.
